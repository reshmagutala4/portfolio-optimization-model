# Portfolio Optimization Model

## Overview
Modern portfolio Theory based portfolio optimization model implemented using Excel (Solver, Dashboard) and Python (Pandas, NumPy, Matplotlib). The objective is to determine optimal asset allocation that maximizes risk-adjusted return.
## Tools & Technologies
- Microsoft Excel (Solver, Dashboard Desgin)
- Python
- NumPy
- Matpltlib
## Methodology
- Calculated historical returns of selected assets
- Computed covariance matrix
- Optimized portfolio weights using Sharpe Ratio maximization
- Evaluated expected return and portfolio volatility
- Visualized performance using Matplotlib
## Key Results
- Optimal Asset Allocation Generated
- Expected Return: 11.57%
- Portfolio Volatility: 4.0%
- Sharpe Ratio: 2.89
## Project Workflow
1. Built initial financial model in Excel
2. Applied Solver to optimize portfolio weights
3. Re-implemented the model in Python
4. Validated and visualized results programmatically
## Business Relevance
Demonstrates application of quantitative finance techniques for portfolio construction, risk management, and data-driven investment decision-making.
